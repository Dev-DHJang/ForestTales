# 나비 v05 모션 설계

| 모션 | 프레임 연기 | 재생 |
| --- | --- | --- |
| idle | 가드 자세 → 호흡·귀 움직임·꼬리 스윙·작은 체중 이동 → 시작 자세 | 16f, 8 FPS, loop |
| run | 우향 접지·반동·패싱·하이포인트의 4박 보행, 꼬리·후드·머리가 후행 | 16f, 12 FPS, loop |
| jump | 웅크림 → 수직 이륙 → 체공 → 수직 하강 → 양발 착지·가드 회복 | 16f, 12 FPS, one-shot |

검토 시트는 4×4 배열로, 좌→우·상→하가 프레임 순서다. 이미지는 실제 포즈 변화를 보여 주지만 현재 셀 크기는 128×128이 아니므로 승인 뒤 별도 정규화·프레임 QA가 필요하다.
