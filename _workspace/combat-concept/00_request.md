# 전체 공격 체계 콘셉트 요청

- 요청: Mini Fighter PC, Jump Ultimate Stars, Smash Bros.의 입력·플랫폼 격투 방향을 참고해 ForestTales의 모든 공격 콘셉트와 기술표를 구성한다.
- 범위: 입력 의미, 연계·방어·자원 규칙, 세 캐릭터의 공격 정체성, Phase 도입 순서, 문서·데이터 계약·QA.
- 비범위: Phase 1 전투 코드, hitbox·피해·프레임 수치, 현재 Phase 0 터치 UI 변경, Android 실제 기기 검증, 신규 공격 이미지의 런타임 등록.
- 사용자 확정: 3키(약·강·특), 방향패드, 짧은 분기 연계, 특수기 쿨다운, 별도 궁극기 게이지, 자현 3·묘령 4·나비 2 기본 연계.
