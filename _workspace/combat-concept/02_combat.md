# 전투 명세 요약

- 기본 약연계는 각 입력마다 다음 단계로 진행하며 자동 완주하지 않는다. 빗나가도 이어지지만 자동 접근은 없다.
- 피니시 전 적중은 약·방향 강·특수 중 하나로 분기하고, 분기한 강·특수와 피니시는 원 연계를 종료한다.
- 위 강 적중만 점프 추격을 열고 체공 공중 공격은 최대 두 번이다. 피니시는 분리 넉백과 회복으로 무한 연계를 막는다.
- 적중 대상은 활성화 단위로 추적한다. 다단은 명시 기술만 허용하고 피격·반복 보정, 행동 복원 금지, 제한된 DI를 적용한다.
- 방어·회피·잡기·차지·궁극기는 ADR-013의 proposed 범위이며 Phase 3 이후에만 구현·실기기 검증한다.
- 자현의 기존 공격 시안은 `_workspace/character-attack-motion-ja-hyun/`에 기본 약연계 후보로 보존한다. 명시 승인 전 이 콘셉트가 새로운 런타임 공격 자산을 등록하지 않는다.
