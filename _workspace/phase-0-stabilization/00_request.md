# Phase 0 안정화 요청

## 목표

- 현재 미커밋 산출물과 승인 자산을 보존해 재현 가능한 Phase 0 기준선을 만든다.
- 계약, 하네스, Android와 Git 상태를 검증하고 `origin/develop`에 통합한다.

## 범위

- 나비 v05 외형 보호 계약의 잘못된 테스트 기대값과 활성 문서 표기를 정정한다.
- 완료된 workspace 상태를 운영 색인에 반영한다.
- 전체 로컬 검사, Android debug export, APK 계약과 에뮬레이터 생명주기를 재검증한다.
- 기존 비추적 증적과 승인 자산을 보존해 feature 브랜치 PR로 `develop`에 병합한다.

## 제외

- Phase 1 전투, 실제 비전투 UI 화면, 새 이미지·모션·오디오와 온라인 기능.
- Resource 스키마, 의미 입력 ID, 런타임 전투와 `main` 브랜치 변경.
- 기존 생성 APK와 캐시를 소스 산출물로 등록하는 작업.

## 불변 조건과 수용 기준

- 제품 단계는 Phase 0으로 유지한다.
- 승인된 나비 v05는 인간형 얼굴·손·발·체형과 흰 고양이 귀·긴 흰 꼬리를 함께 유지한다.
- 자동 검사와 Android 에뮬레이터 검증이 모두 pass하고 원격 PR 병합 증적이 있어야 완료다.
- 실제 Galaxy S23 Ultra 검증은 미실행으로 명시하며 pass로 기록하지 않는다.
