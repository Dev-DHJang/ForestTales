# 나비 v05 콘셉트 교체 요청

- 요청: 사용자가 제공한 백발·고양이 귀·긴 꼬리·보라/검정 계열 이미지 방향으로 나비의 콘셉트와 기본 모션을 바꾼다.
- 기존 등록: `nabi-concept-v01`, v04 chibi 인간형 근접 격투가, idle/run/stationary jump 런타임 패키지.
- 변경 방향: 인간형 3등신 여성 격투가를 유지하되, 백은발·흰 고양이 귀·긴 흰 꼬리·보라/검정/흰색 스트리트 파이터 의상·짧은 발톱 장갑으로 갱신한다.
- 범위: 콘셉트와 idle/run/제자리 jump의 검토 시안. 전투 규칙·CharacterData 능력치·공격 자산·Phase 0 장면은 범위 밖이다.
- 권리 경계: 제공 이미지는 사용자 제공 시각 방향 참고이며 출처·재사용 허가는 확인되지 않았다. 원본 캐릭터·얼굴·헤어 배치·의상 구성·문양·소품·포즈를 복제하지 않은 독창 후보만 생성하며, 확인 전 manifest에 등록하지 않는다.
