# 요청

- 목표: 캐릭터 디자인 관련 규칙을 역할 스킬과 하네스 운영 경계에 반영한다.
- 현재 Phase: 0.
- 범위: 캐릭터 디자인 스킬·브리프/QA 양식·팀 명세·하네스 정적 검사.
- 제외: 승인 캐릭터의 외형 계약 값, PNG·manifest·CharacterData·전투 규칙 변경.
- 불변 조건: 외형 계약은 표현 전용이며 전투 판정에 영향을 주지 않는다. 승인 자산은 사용자 명시 승인 없이 변경하지 않는다.
- 담당: character-design, contracts(계약 소유 경계), qa, orchestrator.
