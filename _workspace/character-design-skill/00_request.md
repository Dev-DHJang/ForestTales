# 캐릭터 디자인·승인 스킬 요청

## 목표

입력 기반으로 독창적 ForestTales 전투 캐릭터 콘셉트를 만들고, QA와 사용자 명시 승인 뒤에만 캐릭터 자산을 등록하는 repo-local 스킬을 하네스에 추가한다.

## 범위

- `forest-tales-character-design` 스킬과 조건부 브리프·검토 참조 문서.
- 팀 라우팅, 이미지·QA 역할 경계와 하네스 검사 갱신.
- 이 변경의 QA·종료 증적.

## 제외

- 새 캐릭터 이미지 생성, 사용자 승인 자산 등록, CharacterData·전투·애니메이션 구현.
- 첨부 참고 이미지의 이동·복사·등록.

## 수용 기준

- 필수 입력, 독창성·권리 경계, 시안→QA→명시 승인→등록 순서가 스킬에 있다.
- 승인 전 `assets/character/` 및 manifest 쓰기를 금지한다.
- 승인 후 캐릭터별 콘셉트 경로와 manifest 필드를 결정적으로 안내한다.
- team-spec과 verify-harness가 14개 역할과 새 라우팅을 검증한다.
