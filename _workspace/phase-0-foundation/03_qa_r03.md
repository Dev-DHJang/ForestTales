pass — 사용자 승인 package ID 전환 뒤 로컬·Android 에뮬레이터 범위 회귀가 통과했다.

## 변경 검증

- `export_presets.cfg`: `com.foresttales.welllbeing` — pass.
- `scripts/verify-android-package.sh`: 생성 APK의 동일 package ID, API 29/36, ABI와 개발 파일 제외 — pass.

- `./scripts/verify.sh` — pass.
