# 이미지 산출물

- `assets/ui/asset-requirements.csv`에 61개 `IMG/*` 슬롯, 고유 출력 경로, 형식, 비율, 우선순위, 상태, 승인 의존성과 소스 참조를 기록했다.
- 자현=mouse, 묘령=rabbit, 나비=cat-theme를 승인 콘셉트 경로에 연결했다.
- fox, wolf, deer, raccoon, extra-01은 `character-approval-required` 상태로 차단했다.
- 모든 장신구 행은 `no-rarity-required`, Splash는 `no-character-required` 의존성을 가진다.
- `forest-arena-image-design` 스킬에 승인 게이트를 지키는 배치 프롬프트를 추가했다.
- 이번 작업에서는 이미지를 생성하거나 기존 캐릭터 manifest를 변경하지 않았다.
