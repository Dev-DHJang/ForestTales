# UI 산출물

- `docs/ui/non-combat-ui-v01.json`에 24개 화면 ID, 그룹, 요구, 이미지 슬롯과 runtime gate를 고정했다.
- `docs/ui/penpot-setup.md`에 1920×1080 기준, 밝은 비픽셀 판타지 숲 방향, safe area, 로컬 MCP와 구현 게이트를 기록했다.
- Splash 무캐릭터, 장신구 무등급과 `MISSING ASSETS` 규칙을 UI 계약에 포함했다.
- `forest-arena-ui` 스킬에 Penpot 절차와 master prompt를 연결했다.
- Godot 1280×720 런타임 해상도와 기존 Phase 0 장면은 유지했다.
- 이번 작업에서 실제 Penpot 파일과 Godot 비전투 화면은 수정하지 않았다.
