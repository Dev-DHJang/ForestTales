# 제품 산출물

- `docs/DECISIONS.md`에 accepted ADR-014와 ADR-015를 추가했다.
- ADR-011은 ABI·최소 Android·기기 기준을 유지하고 기존 package ID 부분만 ADR-014로 superseded했다.
- 제품 문서에는 Forest Arena 명칭, 미래 다섯 모드, 최대 8명, 팀당 1~4명과 장신구 무등급을 반영했다.
- 현재 Phase 0와 미래 제품 규칙을 분리했다. 계정·상점·랭크·소셜·온라인 구현 게이트는 열지 않았다.
- 로컬 폴더와 GitHub 원격 이름은 외부 식별자로 유지했다.
