# 캐릭터 디자인 스킬 변경

## 입력과 프롬프트

- 모든 사용자 설정을 단일 표로 수집하고 필드별 자리표시자를 가진 고정 프롬프트에 원문 반영한다.
- 필수값 누락·모호성은 해당 필드 재질문으로 처리한다.

## 작화와 승인 경계

- 기본 참고는 ja-hyun·myo-ryung이며, 공통 시각 언어만 적용한다.
- Phase·manifest 권리 기록은 저장소에서 자동 반영한다.
- 승인 전에는 draft 작업 경로만 사용하고, 시안 승인 후 이름·ID와 등록 확인을 순차 수집한다.

## 소비자와 위험

- imagegen 시안과 qa 검토가 소비하며, 등록 뒤에만 animation·contracts·combat가 후속 소비한다.
- 고유 캐릭터 요소 복제와 미확인 참고 자료 사용은 QA fix 또는 redo 대상이다.
