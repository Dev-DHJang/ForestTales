# 캐릭터 콘셉트 프롬프트 수집·생성 스킬 갱신 요청

## 목표

전체 사용자 입력 양식을 먼저 수집하고, 답변을 원문대로 캐릭터 콘셉트 프롬프트에 반영하는 ForestTales 캐릭터 디자인 스킬을 만든다.

## 범위

- `forest-tales-character-design`의 입력 수집, 작화 참조, 시안·승인 흐름 갱신.
- 재사용 가능한 생성 프롬프트 및 브리프·QA 참조 문서 추가.
- 스킬·하네스 검증과 수동 회귀 증적.

## 제외

- 새 캐릭터 이미지 생성, 사용자 승인 자산 등록, CharacterData·전투·애니메이션 변경.
- 기존 승인 캐릭터 이미지나 manifest 변경.

## 수용 기준

- 전체 입력 양식을 한 번에 묻고, 누락 값은 생성 전 재질문한다.
- ja-hyun·myo-ryung의 공통 시각 언어만 기본 참고로 기록한다.
- 시안 승인 뒤에만 이름·ID를 수집하고, 별도 등록 확인 전 자산을 쓰지 않는다.
