# 나비 기본 2연계 r01 프레임 계획

- 우향 원본, 4×4·16포즈, 좌→우·상→하, 12 FPS one-shot. 지상 pivot은 발바닥 중앙이며 좌향은 향후 수평 반전한다.
- `attack_light_combo_01`: 비공격 손 가드 → 낮은 전진 발톱 잽 → 가드 회복.
- `attack_light_combo_02`: 낮은 가드 → 양팔 개방 → 큰 교차 발톱 할퀴기 → 긴 낮은 회복. 꼬리는 몸통 회전 후행을 표현하며 VFX는 사용하지 않는다.
- 승인 뒤에만 2048×128 RGBA와 SpriteFrames로 정규화한다.
