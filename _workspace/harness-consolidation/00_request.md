# 요청

## 목표

활성 Forest Arena 하네스를 14개 역할로 통합하고, 역할·증적·버전 관리 규칙과 Phase 2 상태를 정합화한다.

## 범위

- UI, 2D 애니메이션, 오케스트레이터로 중복 역할의 소유권 이동.
- 활성 스킬·하네스·Godot 리소스 문서의 한국어 중심 정리.
- 동적 역할 검증, ADR-018, 최소 증적과 일반 원격 통합 정책.

## 제외와 불변 조건

- 과거 `_workspace` 기록과 ADR-014·017의 당시 사실은 재작성하지 않는다.
- `ForestArenaResources`, 337개 논리 리소스, 22개 품질 변형, 외형 승인 경계, Phase 7 온라인 게이트와 Android 식별자는 유지한다.
- 실제 물리 Android 기기 검증은 연결되지 않으면 미검증으로 기록한다.

## 수용 기준

- 팀 명세와 실제 스킬 목록이 동적으로 일치한다.
- 제거 역할의 활성 참조가 없고, 통합 책임과 최소 증적·버전 관리 예외가 문서화된다.
- 하네스·전체 회귀·형식 검사가 통과한다.
