# 묘령 기본 4연계 r01 프레임 계획

- 공통: 우향 원본, 4×4·16포즈, 좌→우·상→하, 12 FPS one-shot. 지상 pivot은 발바닥 중앙이며 좌향은 향후 시각 래퍼 수평 반전을 사용한다.
- `attack_light_combo_01`: 짧은 전진 손타격. 가드 → 짧은 스텝·손타격 → 가드 회복.
- `attack_light_combo_02`: 상승 무릎. 웅크림 → 무릎 상승·귀/리본 후행 → 착지 회복.
- `attack_light_combo_03`: 회전 킥. 체중 전환 → 몸통 회전·수평 발차기 → 회전 회복.
- `attack_light_combo_04`: 도약 회전 킥 피니시. 웅크림 → 전방·상향 도약 → 귀·리본이 크게 열린 회전 킥 → 긴 착지 회복.
- 시트는 `01_r01_drafts/`에만 보관한다. 승인 후에만 2048×128 RGBA와 16개 AtlasTexture SpriteFrames로 정규화한다.
