# 나비 캐릭터 콘셉트 QA r05

## 판정

pass — 사용자 명시 승인에 따른 원본 그대로의 자산 등록.

## 등록 확인

| 기준 | 결과 | 증거 |
| --- | --- | --- |
| 사용자 지정 원본 | pass | 사용자가 지정한 `exec-51d87f73-2fea-4115-ba2a-7b5bb00bd83e.png`와 등록 PNG의 바이트 비교가 일치했다. |
| 등록 경로 | pass | `assets/character/nabi/concept/nabi-concept-v01.png` 및 `design.md`에 저장했다. |
| manifest | pass | 자산 ID, 생성 방식, 권리 상태, 확인일, SHA-256, 수정 이력, 소비 예정 경로를 기록했다. |
| 파일 특성 | pass with user-approved exception | 1086×1448 RGB PNG이며 `hasAlpha: no`다. 체크무늬 배경을 포함한 원본 그대로의 등록을 사용자가 명시적으로 요청했다. 런타임 투명판은 별도 파생 자산으로 처리한다. |

## 경계

이 등록은 콘셉트 표현 자산만 추가한다. CharacterData, 전투 데이터, 애니메이션·아틀라스 및 런타임 투명판은 포함하지 않는다.
