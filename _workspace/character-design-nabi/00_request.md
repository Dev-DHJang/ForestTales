# 나비 캐릭터 콘셉트 요청

## 제공된 입력

| 항목 | 내용 |
| --- | --- |
| character_id (제안) | `nabi` |
| 동물·성별 | 고양이, 여성 표현 |
| 의상 | 타이즈 |
| 전투 정체성 | 근접 격투 |
| 팔레트 | 보라색, 검은색, 노란색 |
| 공격 실루엣 | 오른손 발톱 장갑을 전방으로 내민 단일 대각선 근접 할퀴기; 왼팔은 뒤쪽 가드. X자 팔 교차·X자 효과는 사용하지 않음. |
| 화면 조건 | Android 가로 화면, 최대 줌아웃 |
| 참고 자료 | 제공 없음; 기존 IP·상표·특정 작가 스타일을 참조하지 않음 |

## 다음 결정

공격 실루엣이 확정되면 독창적 3등신 전신 공격 포즈 시안과 QA 검토를 진행한다. 사용자 명시 승인 전에는 `assets/character/` 및 manifest를 변경하지 않는다.

## 방향 변경 — 2026-09-07

- 고양이의 이미지화를 낮추고, 사람 형태에 고양이 콘셉트를 더한 캐릭터로 만든다.
- `ja-hyun`, `myo-ryung`의 승인된 콘셉트 이미지는 프로젝트 공통 작화 언어(3등신, 부드러운 셀 셰이딩, 큰 표정, 스트리트웨어 레이어)의 참고로만 사용한다. 두 캐릭터의 고유 외형·상징·의상·포즈는 복제하지 않는다.

## 사용자 승인 — 2026-09-07

사용자가 나비 v04의 콘셉트 방향을 채택했다. 다만 v04 PNG는 alpha가 없는 RGB 체크무늬 파일이므로, 동일 디자인의 투명 RGBA 판본을 확인하기 전까지 `assets/character/` 등록은 보류한다.
