# 캐릭터 콘셉트 프롬프트·입력 양식

## 사용자 입력 양식

아래 표를 한 번에 제시하고 모든 칸의 답을 받는다. 값은 생성 프롬프트의 같은 이름의 자리표시자에 원문대로 넣는다.

| 구분 | 입력 항목 |
| --- | --- |
| 기본 설정 | 동물 모티브, 성인 여부, 성별 표현, 나이대/인상, 게임 내 역할, 주인공과의 관계 |
| 신체 경계 | 인간형/수인화 수준, 필수 종 특징, 각도 한정 특징, 금지 신체 구조 |
| 성격·연출 | 성격, 감정 키워드, 포즈 느낌, 표정 느낌 |
| 의상·소품 | 의상 콘셉트, 고정 의상 요소, 가변 의상 요소, 시그니처 아이템/무기, 추가 액세서리, 동물 모티브 반영 방식 |
| 색상 | 메인 컬러, 보조 컬러, 포인트 컬러 |
| 프레젠테이션 | 배경 |
| 추가 방향 | 귀여움/멋짐 비율, 실루엣 특징, 강조하고 싶은 포인트, 피하고 싶은 요소 |

## 생성 프롬프트

```text
전신 게임 캐릭터 콘셉트 아트를 제작해줘.

[스타일 고정]
Forest Arena의 승인된 ja-hyun·myo-ryung 캐릭터 로스터에서 공통 시각 언어만 참고한다. 고퀄리티 애니메이션 게임 캐릭터 일러스트 스타일, 귀엽지만 멋있는 SD/chibi(슈퍼 디포르메) 비율, 큰 머리와 작은 체구의 3등신 전신, 크고 반짝이는 표현력 있는 눈, 작은 코, 부드럽고 둥근 얼굴형, 역동적인 액션 포즈를 사용한다. 매끈하고 세련된 반입체 애니메이션 렌더링, 부드러운 피부 명암, 깔끔하고 선명한 라인, 은은한 조명, 디테일이 풍부하지만 가독성 좋은 의상 디자인을 유지한다.

같은 모바일 액션 RPG의 캐릭터 로스터처럼 보이게 하되, 참조 캐릭터의 종·얼굴·머리·의상·상징·소품·색 조합·포즈를 복제하지 않는다. 공통 얼굴 비율, 눈 표현, 신체 비율, 의상 디테일 밀도, 광택감 있는 마감, 작은 화면에서 읽히는 실루엣만 참고한다. 동물 모티브, 성별, 색상, 의상 콘셉트, 성격은 새 캐릭터에 맞게 독창적으로 설계한다.

의상은 스포티한 스트릿웨어, 테크웨어, 아이돌풍 액세서리, 귀여운 동물 모티브, 오버사이즈 운동화, 스트랩, 리본, 버클, 참 장식, 배지, 장갑, 작은 상징 아이콘을 조합한 방향이다.

[캐릭터 기본 설정]
동물 모티브: {동물 모티브}
성인 여부: {성인 여부}
성별 표현: {성별 표현}
나이대/인상: {나이대/인상}
게임 내 역할: {게임 내 역할}
주인공과의 관계: {주인공과의 관계}

[신체 및 종 모티브 경계]
인간형/수인화 수준: {인간형/수인화 수준}
필수 종 특징: {필수 종 특징}
각도 한정 특징: {각도 한정 특징}
금지 신체 구조: {금지 신체 구조}

[성격 및 연출]
성격: {성격}
감정 키워드: {감정 키워드}
포즈 느낌: {포즈 느낌}
표정 느낌: {표정 느낌}

[의상 및 소품]
의상 콘셉트: {의상 콘셉트}
고정 의상 요소: {고정 의상 요소}
가변 의상 요소: {가변 의상 요소}
시그니처 아이템/무기: {시그니처 아이템/무기}
추가 액세서리: {추가 액세서리}
동물 모티브 반영 방식: {동물 모티브 반영 방식}

[색상 팔레트]
메인 컬러: {메인 컬러}
보조 컬러: {보조 컬러}
포인트 컬러: {포인트 컬러}

[디자인 요구사항]
- 필수 종 특징과 명시적으로 허용된 표현 수단만 사용해 동물 모티브가 한눈에 알아보여야 한다.
- 명시적으로 허용되지 않은 귀·꼬리·모피·주둥이·동물형 손발·역관절 다리를 자동으로 추가하지 않는다.
- 각도 한정 특징은 지정된 시점에서만 허용하고 정면 필수 실루엣으로 바꾸지 않는다.
- 기존 로스터의 공통 시각 언어를 유지하면서도 고유한 실루엣을 가진다.
- 작은 인게임 아이콘으로도 식별 가능한 강한 실루엣을 가진다.
- 귀엽지만 자신감 있는 액션 포즈를 사용하며, 성격이 표정·시선·손동작·몸 기울기와 허용된 종 특징의 움직임에 드러난다.
- 시그니처 액세서리 또는 아이템이 분명하게 보이고, 동물 모티브는 허용된 헤어 실루엣·문양·장식·장비·움직임 느낌에 반영한다.
- 전신이 보이는 정면 또는 3/4 구도의 깔끔한 프레젠테이션으로 표현한다.
- 배경은 {배경}으로 한다.

[추가 디자인 방향]
귀여움/멋짐 비율: {귀여움/멋짐 비율}
실루엣 특징: {실루엣 특징}
강조하고 싶은 포인트: {강조하고 싶은 포인트}
피하고 싶은 요소: {피하고 싶은 요소}

[피해야 할 요소]
실사풍, 반실사풍, 성숙한 체형, 8등신 비율, 서양 카툰풍, 코믹북 스타일, 픽셀아트, 벡터풍, 수채화풍, 유화풍, 러프 스케치, 저퀄리티, 어두운 판타지 갑옷, 공포스러운 분위기, 괴물 같은 인상, 실제 동물 얼굴, 퍼리 실사풍, 지저분한 디자인, 흐릿한 색감, 기존 로스터와 다른 그림체, 복잡한 배경, 흐릿한 이미지.
```

`{...}` 자리표시자는 비워 두지 않는다. `없음`도 명시적 값으로 기록하며 빈 값이나 `알아서` 같은 위임 표현은 허용하지 않는다. 사용자 답변이 위의 제외 조건이나 독창성·권리 경계와 충돌하면 충돌한 항목을 설명하고 대체 답변을 요청한다.
