# Forest Arena Resource Rules
- Bright fantasy forest; carved wood + leaf UI; non-pixel-art.
- Main mouse/rabbit files under `character/main` are authoritative identity resources.
- Accessories have no rarity/grade/star tier.
- Buttons/frames keep ordinary UI copy as native Godot text.
- Do not hardcode quality directories; use `ForestArenaResources`.
- Combat HUD is outside this package.
