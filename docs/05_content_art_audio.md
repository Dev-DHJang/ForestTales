# 05. 콘텐츠·아트·오디오

## 제작 원칙

- 전투 가독성이 장식성보다 우선한다.
- AI와 외부 에셋은 제작 보조이며 전투 타이밍, 충돌 또는 승패의 권위가 아니다.
- 최종 캐릭터, 명칭, UI, 효과, 음악과 애니메이션은 독창적으로 제작한다.
- 외부 에셋이 없어도 기본 도형과 임시 신호로 핵심 개발을 계속할 수 있어야 한다.

## 3등신 캐릭터 파이프라인

    콘셉트 → 3등신 턴어라운드 → 동작별 키 포즈 → 프레임 제작
    → 스프라이트 시트/아틀라스 → SpriteFrames → 교체 가능한 Godot 시각 래퍼

- 머리 약 1, 몸 약 2의 비율을 출발점으로 삼되 종별 실루엣과 공격 포즈를 우선한다.
- 보이는 장식적 돌출부와 게임플레이 판정 크기를 동일시하지 않는다.
- 애니메이션은 AttackData의 의미 단계와 이벤트를 표현하며 프레임이 판정을 결정하지 않는다.
- image-design은 콘셉트·정적 이미지를, 2d-animation은 프레임·아틀라스·런타임 매핑을 소유한다.

## 저장과 권리

- 외부 원본, 프로젝트 파생 원본과 런타임 아틀라스 경로를 분리한다.
- manifest에는 자산 ID, 공급자 또는 생성 방식, URL/출처, 확인 날짜·버전, 라이선스 증적, 해시, 수정 내용과 사용 경로를 기록한다.
- 무료 표시만으로 상업 이용 권리를 간주하지 않으며 상표·유명 캐릭터·참고 이미지 권리를 별도로 확인한다.

## Android 예산과 오디오

- 해상도, 프레임 수, 아틀라스, 메모리, draw call, 화면 내 캐릭터 수와 목표 FPS는 Phase 0 실제 기기 측정 뒤 ADR로 정한다.
- 최대 줌아웃에서 종, 직업, 장신구, 공격 준비와 피격을 형태로 구분한다.
- BGM과 SFX는 의미 이벤트를 소비하며 전투 결과를 만들지 않는다.
- 앱 중단·복귀에서 중복 재생을 막고 오디오가 없어도 핵심 상태를 이해할 수 있게 한다.
