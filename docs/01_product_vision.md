# 01. 제품 비전

## 한 줄 정의

Forest Arena는 독창적인 3등신 동물 캐릭터가 플랫폼에서 위치, 점프, 넉백과 링아웃으로 겨루는 Android 우선 2D 아레나 격투게임이다. 제품 로고 표기는 `FOREST ARENA`, 기술 슬러그는 `forest-arena`다.

## 핵심 기둥

1. 공간 중심 전투: 플랫폼과 위험 경계를 이용한 위치 선택이 승부를 바꾼다.
2. 읽히는 동물 캐릭터: 작은 화면에서도 종, 방향, 공격과 피격 상태를 실루엣으로 구분한다.
3. 직업 변화: 직업은 이동, 기술, 패시브, 취소 규칙과 태그를 바꾼다.
4. 장신구 조합: 매치 전 선택한 장신구가 데이터 기반으로 빌드를 변형한다.

런타임 조합 기준은 다음과 같다.

    기본 캐릭터 + 현재 직업 + 장신구 = RuntimeCombatProfile

## 대상과 개발 원칙

- 엔진은 Godot 4.x, 언어는 typed GDScript를 기본으로 한다.
- Android 10 이상 가로 화면과 터치가 제품 기준이다.
- 데스크톱 Godot, 키보드와 패드는 개발·자동 검사·디버깅 보조다.
- 초기 프로토타입은 한 명의 터치 플레이어와 훈련 상대를 위한 최소 2D 경기로 시작한다.
- 수직 슬라이스의 콘텐츠 수량과 정확한 승리 규칙은 플레이테스트와 ADR로 확정한다.

## 경쟁과 범위

- 직접적인 pay-to-win을 지양한다.
- 경제, 성장, 초기화와 상품 정책은 구현 전에 별도 승인이 필요하다.
- 초기에는 계정, 상점, 결제, 광고, 클라우드 저장, 랭크 매칭, 프로덕션 백엔드와 최종 콘텐츠를 만들지 않는다.
- 온라인은 로컬 전투와 데이터 계약이 안정되고 Phase 7 ADR이 승인된 뒤에만 다룬다.
- 다른 작품이나 특정 작가의 고유 표현을 복제하지 않는다.

## 승인된 미래 제품 규칙

- 모드는 Story, Solo, Team, AI, Practice 다섯 가지다.
- 전체 참가자는 최대 8명이며 Team은 팀당 1~4명, 전체 최대 8명이다.
- 장신구는 플레이 방식을 바꾸는 장비지만 등급·희귀도 체계를 갖지 않는다.
- 이 규칙은 미래 화면과 데이터 설계 기준이다. Phase 2 종료 상태에서는 온라인·계정·상점·랭크·경제·소셜 구현을 추가하지 않는다.
